# customer-churn-prediction-using-machine-learning
# Customer Churn Prediction

## 📌 Problem Statement
The goal of this project is to predict whether a customer will leave (churn) or stay with a company based on their usage patterns and account information.

---

## 📊 Overview
Customer churn is a critical problem for businesses. This project uses machine learning to analyze customer data and predict churn, helping companies take proactive actions to retain customers.

---

## 🛠 Tools & Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

---

## 📈 Process
- Data cleaning and preprocessing
- Handling missing values
- Encoding categorical variables
- Splitting data into training and testing sets
- Model training using Random Forest Classifier
- Model evaluation using accuracy and confusion matrix

---

## 📊 Model Performance
- Achieved good prediction accuracy on test data
- Evaluated using accuracy score and confusion matrix

---

## 🔍 Key Insights
- Certain features like contract type and monthly charges strongly influence churn
- Customers with shorter contracts are more likely to churn
- The model can help identify high-risk customers
